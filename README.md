# Timothy Chen

Computer Engineering at UC San Diego. Lately I've been getting into GPU programming, starting with a CUDA matrix multiply I'm slowly making faster. Before that I mostly built with LLMs: multi-model systems and the apps around them. I also co-founded LatinXTech, a tech education nonprofit that ran programs in 14 schools for 1,000+ students across the Bay Area.

## Right now

**[cuda-sgemm](https://github.com/TimothyChennn/cuda-sgemm)**: taking a naive CUDA matmul and working it up toward cuBLAS one kernel at a time. Three kernels in, sitting at about 21% of cuBLAS on a T4. Still a long way to go.
